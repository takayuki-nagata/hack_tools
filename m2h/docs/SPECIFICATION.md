# MSP430 to Hack Transpiler (`m2h`) Specification

This document specifies the architecture, memory model, calling convention (ABI), instruction mapping rules, and runtime environment for the **`m2h`** transpiler and **`hcc`** (Hack C Compiler frontend).

---

## 1. Overview

The `m2h` transpiler translates **MSP430 assembly code (`.s`)** generated by GCC into **Hack assembly code (`.asm`)**, which can then be assembled into Hack machine code (`.hack`, `.bin`, `.coe`) using `has`.

### Pipeline
```text
C Source (.c)
   │
   ▼ (msp430-gcc -S -O2 -ffreestanding -fno-exceptions -nostdlib -mhwmult=none)
MSP430 Assembly (.s)
   │
   ▼ (m2h)
Hack Assembly (.asm)
   │
   ▼ (has)
Hack Machine Code (.hack / .bin / .coe)
```

## 2. Hardware Architecture & Memory Model

### Architectural Comparison
| Characteristic | MSP430 (GCC Target) | Hack CPU |
| :--- | :--- | :--- |
| **Word Size** | 16-bit | 16-bit |
| **Address Space** | 16-bit word/byte addressable (64 KB) | 16-bit word addressable (32 KW Data + 32 KW Instruction) |
| **Registers** | `R0`..`R15` (16 general/special registers) | `D` (data), `A` (address/constant), `M` (RAM[A]) |
| **Memory Architecture** | Von Neumann | Harvard (Separate ROM and RAM) |
| **Hardware Stack** | Stack via `SP` (R1) | Software stack via `RAM[SP]` (`RAM[0]`) |

### Hack RAM Layout
The transpiled program utilizes Hack's data memory (`RAM`) as follows:

```text
+-----------------------+ 0x0000 (0)
| SP (Stack Pointer)    | RAM[0]  -> Current top-of-stack address
| LCL (Local Base)      | RAM[1]
| ARG (Argument Base)   | RAM[2]
| THIS / THAT           | RAM[3] / RAM[4]
| R5 .. R15             | RAM[5] .. RAM[15] -> Virtual registers (R0..R15)
+-----------------------+ 0x0010 (16)
| Static & Global Vars  | RAM[16] .. RAM[255]
| Temporary Variables   |
+-----------------------+ 0x0100 (256)
| Stack Area            | RAM[256] .. RAM[16383] (Stack grows upwards)
| (Local vars, frames)  |
+-----------------------+ 0x4000 (16384)
| SCREEN Memory Map     | RAM[16384] .. RAM[24575]
+-----------------------+ 0x6000 (24576)
| KBD (Keyboard Input)  | RAM[24576]
+-----------------------+
```

## 3. Register Mapping & Calling Convention (ABI)

### Register Mapping Table
| MSP430 Register | Name / Role | Hack RAM Location | Notes |
| :--- | :--- | :--- | :--- |
| `r0` (`pc`) | Program Counter | *(Hardware PC)* | Handled via labels and Hack jumps (`@label; 0;JMP`) |
| `r1` (`sp`) | Stack Pointer | `RAM[SP]` (`RAM[0]`) | Stack pointer holding the current top address |
| `r2` (`sr`) | Status Register | `D` register / condition | Evaluated directly in Hack ALU / conditional jumps |
| `r3` (`cg`) | Constant Generator | Immediate values (`@N`) | Generated as immediate constants (`@0`, `@1`, etc.) |
| `r4` .. `r11` | Callee-saved general registers | `RAM[4]` .. `RAM[11]` | Preserved across function calls if modified |
| `r12` | 1st Argument / Return Value | `RAM[12]` | Function argument 1 and return value |
| `r13` | 2nd Argument / Scratch | `RAM[13]` | Function argument 2 and temporary register |
| `r14` | 3rd Argument / Scratch | `RAM[14]` | Function argument 3 |
| `r15` | 4th Argument / Scratch | `RAM[15]` | Function argument 4 |

## 4. Addressing Modes & Hack Code Generation

### 1. Register Direct (`Rn`)
- **Read**:
  ```assembly
  @Rn
  D=M
  ```
- **Write**:
  ```assembly
  @Rn
  M=D
  ```

### 2. Immediate (`#imm` / `#symbol`)
- **Read**:
  ```assembly
  @imm
  D=A
  ```

### 3. Register Indirect (`@Rn`)
- **Read**:
  ```assembly
  @Rn
  A=M
  D=M
  ```
- **Write**:
  ```assembly
  @Rn
  A=M
  M=D
  ```

### 4. Register Indirect with Autoincrement (`@Rn+`)
- **Read**:
  ```assembly
  @Rn
  A=M
  D=M
  @Rn
  M=M+1
  ```

### 5. Indexed (`offset(Rn)` / `var(Rn)`)
- **Read**:
  ```assembly
  @Rn
  D=M
  @offset
  A=D+A
  D=M
  ```
- **Write**:
  ```assembly
  @offset
  D=A
  @Rn
  D=D+M
  @R13
  M=D        // Temporary address pointer
  // (prepare value in D)
  @R13
  A=M
  M=D
  ```

### 6. Absolute / Symbolic (`&var` / `var`)
- **Read**:
  ```assembly
  @var
  D=M
  ```
- **Write**:
  ```assembly
  @var
  M=D
  ```

## 5. Instruction Transpilation Rules

| MSP430 Instruction | Meaning | Hack Assembly Mapping |
| :--- | :--- | :--- |
| `mov src, dst` | `dst = src` | Read `src` into `D` $\to$ Write `D` into `dst` |
| `add src, dst` | `dst += src` | Read `src` into `D` $\to$ `@dst; M=D+M` |
| `sub src, dst` | `dst -= src` | Read `src` into `D` $\to$ `@dst; M=M-D` |
| `and src, dst` | `dst &= src` | Read `src` into `D` $\to$ `@dst; M=D&M` |
| `bis src, dst` | `dst |= src` | Read `src` into `D` $\to$ `@dst; M=D|M` |
| `bic src, dst` | `dst &= ~src` | Read `src` into `D` $\to$ `D=!D` $\to$ `@dst; M=D&M` |
| `clr dst` | `dst = 0` | `@dst; M=0` |
| `inc dst` | `dst += 1` | `@dst; M=M+1` |
| `dec dst` | `dst -= 1` | `@dst; M=M-1` |
| `inv dst` | `dst = ~dst` | `@dst; M=!M` |
| `neg dst` | `dst = -dst` | `@dst; M=-M` |
| `tst dst` | `dst - 0` | `@dst; D=M` (leaves value in `D`) |
| `cmp src, dst` | `dst - src` | Read `src` into `D` $\to$ `@dst; D=M-D` (leaves comparison in `D`) |
| `jeq / jz label` | Jump if equal (`D == 0`) | `@label; D;JEQ` |
| `jne / jnz label` | Jump if not equal (`D != 0`) | `@label; D;JNE` |
| `jge label` | Jump if $\ge 0$ | `@label; D;JGE` |
| `jl label` | Jump if $< 0$ | `@label; D;JLT` |
| `jmp label` | Unconditional jump | `@label; 0;JMP` |
| `push src` | Push to stack | Read `src` into `D` $\to$ `@SP; A=M; M=D; @SP; M=M+1` |
| `pop dst` | Pop from stack | `@SP; M=M-1; A=M; D=M` $\to$ Write `D` into `dst` |
| `call #fn` / `call fn` | Call subroutine | `@RET_N; D=A; @SP; A=M; M=D; @SP; M=M+1; @fn; 0;JMP; (RET_N)` |
| `ret` | Return from subroutine | `@SP; M=M-1; A=M; A=M; 0;JMP` |

## 6. Startup Runtime (`crt0.asm`)

Every standalone executable produced by `m2h` includes an initial startup sequence:

```assembly
// Initialize Stack Pointer to RAM[256]
@256
D=A
@SP
M=D

// Call main() with return address set to __HALT
@__HALT
D=A
@SP
A=M
M=D
@SP
M=M+1
@main
0;JMP

(__HALT)
// Infinite termination loop
@__HALT
0;JMP
```

## 7. Optimal GCC Compilation Flags

When using `hcc` or manually running `msp430-gcc`:

```bash
msp430-gcc -std=c99 -S \
  -O2 \
  -ffreestanding \
  -fno-asynchronous-unwind-tables \
  -fno-exceptions \
  -fno-builtin \
  -nostdlib \
  -Wall -Wextra \
  source.c -o source.s
```

- `-O2`: Enables register allocation, dead code elimination, and constant folding.
- `-ffreestanding` & `-nostdlib`: Eliminates host standard library runtime dependencies.
- `-fno-asynchronous-unwind-tables`: Disables DWARF CFI directives.
- `-mhwmult=none`: Employs software arithmetic rather than hardware multiplier peripherals.
